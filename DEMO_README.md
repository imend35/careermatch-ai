# Synthetic demonstration fixtures

All files in `sample_data/` and `outputs/` are fictional and safe for a public portfolio repository. They do not represent a real job advertisement, real candidate, or a real application.

- `sample_data/synthetic_candidate_cv.md`: readable synthetic CV.
- `sample_data/synthetic_candidate_cv.json`: structured synthetic profile.
- `sample_data/sample_job_description.txt`: synthetic 9-requirement / 7-responsibility job posting.
- `outputs/01_requirements.json`: example of Prompt 01 output.
- `outputs/02_cv_matching.json`: example of Prompt 02 output.
- `outputs/03_application_draft.json`: example of Prompt 03 output.
- `outputs/04_quality_validation.json`: example of Prompt 04 output.

**Important:** Outputs are _illustrative hand-authored / deterministic fixtures_ generated by `make_demo_outputs.py`, not outputs from executing a language model. Scores are example rubric values, not ATS scores or controlled experimental results. The QA status is REVIEW and human approval is PENDING. No application is submitted.

To regenerate from the project root, run `python make_demo_outputs.py` (Python standard library only). Run the same script after changing fixtures only if you also update its hardcoded evidence mappings; it is a demonstration fixture generator, not a general-purpose LLM pipeline.
